# NieR Re[in]carnation PC port 1.1

## What's new

* **Your phone save works on PC now (and the other way round).** On the phone, use Bunker's
  *Export save backup*, then in the launcher go to Settings › Saves › **Import from phone**. It comes in
  as a new save, your existing saves stay untouched. Want to take a PC save to your phone? Hit
  **Export** on it and import that file in Bunker.
* **Server updated to Bunker 1.12.18.** Brings Bunker's latest fixes on top of
  [Lunar Tear](https://github.com/Walter-Sparrow/lunar-tear): missions that could never complete now
  count, missing event summons are back so their tickets can be spent, and more.
* **Alt+Enter** flips between full screen and a window while you play.
* **Update check:** the launcher tells you when a new version is out (Settings › System › Updates,
  you can turn it off). It only asks GitHub for the latest release, nothing else.
* **ZIP asset dumps** work in the setup now, not just `.7z`, even when the files sit inside a folder
  in the archive.

## Updating from 1.0

Close the game and the launcher, then unzip `NieR-Reincarnation-PC-v1.1.zip` over your game folder
(the one with `NieR.exe`) and say yes to replacing files. Your saves, settings and game files stay. The
first start makes a backup of your save by itself, since the server version changed.

New here? Same zip, unzip it anywhere and check the README.

## Heads up

* The exes aren't signed, so SmartScreen or your antivirus might complain.
* Found a bug? Settings › System › **Export logs**, then attach the zip to an issue.
